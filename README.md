# What this is:
Some **C++** code that writes ASCII characters to a 16 by 16 grid with built in buffering.

# How to run:
 - Compile the code with `make build` of just `make`
 - Execute the code with `make run`
 - If you're on windows i recomend installing g++ via zpratikpathak 's one liner g++ installer:
 - 
https://github.com/zpratikpathak/windows-11-g-plus-plus-installation-script/tree/home#-quick-start-one-liner-installation
