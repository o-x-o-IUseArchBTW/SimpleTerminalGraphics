# What this is:
A **C++** library in the `Library` folder that draws a 16*16 grid and some text.
Also some c++ code to use said library to let users interact with the library.
Its not well documented but its pretty self explanatory 

# How to run:
 - Compile the code with `make build` or just `make` or use `buildandrun` to build it the run the result
 - Execute the code with `make run`
 - enter X value press enter then enter Y value then enter 1 to stop or 0 to continue
 - If you're on windows i recommend installing g++ via https://github.com/zpratikpathak 's one liner g++ installer:

https://github.com/zpratikpathak/windows-11-g-plus-plus-installation-script/tree/home#-quick-start-one-liner-installation
